# Fuente de Datos

El dataset incluido en Ubigeo Perú deriva de la fuente pública CONCYTEC/ubigeo-peru:

https://github.com/CONCYTEC/ubigeo-peru

La fuente documenta concordancias entre códigos de UBIGEO de INEI, RENIEC y SUNAT.

## Uso en este plugin

El archivo `data/ubigeo-peru.json` fue preparado como estructura optimizada para selectores dependientes de departamento, provincia y distrito en WordPress.
